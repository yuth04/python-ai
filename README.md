# AI Visual Search

An AI-powered visual search service built with **Python, Flask, and OpenCLIP**.

This service allows users to upload a product image and find visually similar products from the VENDO product dataset. Instead of relying only on product names or keywords, the system uses image embeddings to understand the visual characteristics of products.

---

## 🚀 Features

- 🖼️ Search products using an image
- 🤖 AI-powered image feature extraction
- 🔍 Find visually similar products
- 📊 Calculate image similarity using cosine similarity
- 🛍️ Designed for e-commerce product search
- ⚡ Fast image embedding and similarity matching
- 📦 Search through a local product image dataset
- 🔢 Return ranked search results
- 🌐 Flask REST API
- 🔗 Laravel/VENDO integration
- 🐳 Docker support
- ☁️ Deployment configuration for Hugging Face
